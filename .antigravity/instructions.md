# Antigravity System Directives

- **Framework**: Laravel 11 / PHP 8.2+
- **Database**: MySQL
- **CSS Engine**: Tailwind CSS
- **Payment Gateway**: Midtrans Snap & HTTP Notification Webhook
- **Notification Service**: WhatsApp API Gateway
- **Arsitektur & Standar**: Semua kode wajib modular, menerapkan Model-View-Controller (MVC) standar Laravel, dan migration yang clean dengan foreign key constraints.
